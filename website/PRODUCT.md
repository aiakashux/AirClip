# Airclip website

## Register

brand

## Users

Professionals arriving from LinkedIn who use a Mac and an Android phone.

## Product Purpose

Explain Airclip's local clipboard sharing and provide separate Mac and Android beta downloads. Launch the website first; feedback collection is explicitly deferred.

## Brand Personality

Simple, quiet, personal. The user selected Dockset as the reference: generous white space, plain sans-serif type, concise copy, and clear downloads. Product spelling is Airclip. Describe the launch only as Beta, without pricing language.

## Anti-references

Avoid information-heavy marketing pages, invented testimonials, unnecessary sections, and inactive feedback forms.

## Design Principles

- Explain the Mac and Android connection immediately.
- Make both downloads visible together.
- Use existing Airclip identity and original examples. The revised brief calls for very little fifth-grade copy, visual setup steps, photo/link/text sharing examples, and subtle motion using the Emil design skill.
- Disclose actual installation requirements.
- Keep the website static and deploy to the user's preferred Vercel account.

## Accessibility & Inclusion

Use semantic HTML, keyboard access, visible focus, readable contrast, responsive layouts, and no required animation.

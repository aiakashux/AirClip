Privacy

Clipboard transfers stay on your local network. Update checks and optional analytics use the internet.

Analytics is off by default and can be changed in Settings. When enabled, Airclip sends at most one anonymous aggregate each day containing app version, platform, major OS version, and counts for pairing, first transfer, update activity, and failures.

Airclip never sends clipboard content, images, URLs, domains, hashes, device names or identifiers, Wi-Fi names, keys, or exact activity times. Vercel and GitHub may retain ordinary request metadata such as IP address and request time.

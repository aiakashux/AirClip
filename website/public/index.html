A few things to know.

Install on Mac+

Open the download. Drag Airclip to Applications.

This beta is not Apple-notarized. If your Mac blocks it, read Apple’s guide.

Install on Android+

Open the APK. Allow installs from your browser if asked.

Replacing an old test build? Save your clips first. Uninstalling deletes them.

Send from Android+

Tap Share, then Airclip. Or use Send in the app.

Privacy+

Clips travel over your local Wi-Fi. No cloud storage.

No website analytics. Vercel and GitHub keep basic access logs.

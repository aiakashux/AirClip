# Motion

Native radio controls switch photo, link, and text examples without JavaScript. Each pointer-selected example plays one short transfer; it does not loop. Keyboard selection and reduced-motion preferences skip the animation. Pointer presses use a 160 ms transform transition, with hover motion limited to hover-capable devices.

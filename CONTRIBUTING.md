# Contributing to AirClip

## Branches

| Branch | Purpose |
|--------|---------|
| `main` | Latest stable code |
| `staging` | Active development |

Work on `staging`. Open PRs into `main` when ready.

## Getting Started

1. Clone the repo
2. Android: open `android/` in Android Studio
3. Mac: open `mac/AirClip.xcodeproj` in Xcode
4. Read [docs/architecture.md](docs/architecture.md) and [docs/protocol.md](docs/protocol.md) first

## Pull Requests

- One concern per PR
- Include what you tested manually
- Use the PR template

## Reporting Issues

Open a GitHub Issue. Include:
- Device + OS version
- Steps to reproduce
- What happened vs what you expected

## Security Issues

Do **not** open a public issue. See [SECURITY.md](SECURITY.md).

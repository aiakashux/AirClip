Meeting notes from the design review session this afternoon. Key decisions made: — Wider window layout (720 × 620) with 16px padding on all sides — Split-pane preview with 16px gap between list and detail — Type indicators per clip: URL, Code, Text, Email, Color, Image — Bottom pill navigation replacing sidebar — Search bar moves icon to right side (Figma 116:917) — Backdrop blur on nav bar and search, no glass morphism Action items: 1. Implement the SwiftUI app window targeting macOS 14+ 2. Use NSVisualEffectView with .ultraThinMaterial as fallback for pre-26 3. Set up SwiftData model for ClipboardItem with seq tracking 4. Wire up WebSocket SyncEngine for real-time delivery 5. Write unit tests for the clipboard monitor suppress logic Design notes: The preview panel should scroll when content exceeds the available area. This is especially important for long text clips — users frequently copy entire meeting notes, code documentation, or email threads that can exceed 1000 words. The pv-content area uses overflow-y: auto so the information panel always stays anchored at the bottom, visible and accessible. The user can scroll up to read earlier content while the metadata (Source, Content type, Characters, Device, Copied) remains fixed below. Typography at 13.5px with line-height 1.65 gives comfortable reading density without feeling cramped. The text color shifts from 50% to 90% white on hover, signaling interactivity.
